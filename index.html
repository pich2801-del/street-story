STREET STORY

การแจ้งเรื่องสามารถใช้หลักฐานเป็น Overlay เท่านั้น

⚠ หมายเหตุ Overlay จะต้องเปิดเสียงทุกกรณี หากไม่มีเสียง จะถือว่าไฟล์คลิป Overlay นั้นเสียทันที ⚠

⚠ ไฟล์คลิป Overlay ก่อนเหตุการณ์หน้า-หลัง 1 นาที หากไม่มีจะไม่รับหลักฐานนั้น ⚠

หลักฐานจะมีระยะเวลาในการส่งไม่เกิน 24 ชั่วโมง

วันและเวลาของหลักฐานจะต้องตรงตามเวลาจริง หากเวลาไม่ตรงจะไม่รับหลักฐานนั้น

🍁 หมวดหมู่ กฎการเล่น แอร์ดรอปแก๊ง (สำหรับแก๊ง)

1.
ผู้ที่มีสตรีมต่อเนื่องอยู่ห้ามเข้าเล่นกิจกรรมทุกกรณี หากมีสตรีมติดต่ออยู่แล้วห้ามเข้าไป ถือว่าเป็น Breaking Roleplay
โทษ : ใบเหลือง + ปรับ 500,000
2.
ห้ามนั่ง นอน หรือใช้ Emote ในขณะที่เล่นกิจกรรม รวมถึงการเก็บ Airdrop จะต้องทำในท่ายืนเท่านั้น
โทษ : ปรับ 500,000 / ครั้ง / คน
3.
ห้ามไม่ให้กระทำการเคลื่อนย้ายพัสดุหรือวัตถุในกิจกรรมโดยเด็ดขาด หากฝ่าฝืนมีโทษ
  • ข้อแนะนำหากทำการหยิบของผิดจะต้องทำการพูด “ขอโทษ” ทันที
โทษ : ปรับ 500,000 / ครั้ง / คน
หมายเหตุ : หากมีการแจ้ง ต้องใช้หลักฐาน Overlay ในการแจ้งเท่านั้น
4.
ทางเซิร์ฟเวอร์ได้กำหนดจำนวนผู้เล่นในหนึ่งทีมไว้ดังนี้
  • แก๊ง : สูงสุด 20 คน ต้องเล่นภายในทีมแก๊งเท่านั้น
โทษ : ปรับ 500,000 / ครั้ง / คน
5.
ผู้เล่นจะต้องมีเพียงทีมเดียวที่เหลือรอด จึงจะสามารถเริ่มทำการเก็บแอร์ดรอปได้
โทษ : ปรับ 500,000 / ครั้ง / คน
6.
ผู้เล่นจะต้องสวมใส่ชุดแก๊งสำหรับการเล่นเท่านั้น
